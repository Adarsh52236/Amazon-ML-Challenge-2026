# Official Dataset Directory

If you prefer placing the official dataset directly inside the repository folder, you can extract or link `student_resource` contents here:

```
data/official/
├── train/
│   ├── train_source1.tsv
│   ├── train_source2.tsv
│   ├── train_source3.tsv
│   └── train_ground_truth.tsv
└── test/
    ├── test_source1.tsv
    ├── test_source2.tsv
    └── test_source3.tsv
```

All data files in this directory are excluded from version control via `.gitignore`.
